# K. Sai Charitha | Portfolio

A single-page personal portfolio built with semantic HTML and CSS. There are no framework or JavaScript dependencies.

## Run locally

Open `index.html` directly in a browser. The page does not require a build step or local server.

## Personal files

- Put your resume PDF at `assets/resume.pdf`; the navigation button already links to that path.
- If you decide to add a profile photo, place it in `assets/images/` (for example, `profile.jpg`). The current design uses a CSS terminal-style visual instead of a photo.
- Update the resume and profile links in `index.html` if the file names or account URLs change.

## GitHub Pages

1. Push this folder to a GitHub repository.
2. Open the repository’s **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing the site and the `/ (root)` folder, then save.
5. Wait for the Pages deployment and open the URL shown in the Pages settings.

Keep `index.html`, `css/`, and `assets/` together at the published root so the relative links continue to work. Add `assets/resume.pdf` before publishing if you want the resume button to open a real document.
