02 / GENERATIVE AI Featured project

Campus RAG Assistant

A retrieval-augmented assistant for college academic and placement documents, built without LangChain. It uses page-aware PDF chunking, sentence-transformer embeddings in ChromaDB, and a relevance threshold to handle out-of-scope questions. A 19-question evaluation suite measured 89.5% retrieval accuracy.
